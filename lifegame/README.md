# ライフゲーム（ワークシート関数版）

マクロ・LAMBDA・反復計算を使わず、`SUM` / `IF` / `OR` / `AND` / `INDEX` だけで動くライフゲームです。
Excel・Google スプレッドシート・LibreOffice Calc で開けます。

## 使い方
1. `lifegame.xlsx` を開く
2. 「初期配置」シートで生きたセルに `1` を入力（プリセット：グライダー、R-ペントミノ、ブリンカー、ヒキガエル）
3. 「ライフゲーム」シートの「世代」（0〜120）を変えると盤面が進む

## シート構成
| シート | 内容 |
|---|---|
| ライフゲーム | 指定世代を `INDEX` で取り出して表示（条件付き書式で塗り分け） |
| 初期配置 | 30×30 の第0世代 |
| 計算 | 第0〜120世代を縦に並べたブロック（各ブロック間に空行） |
| 個体数推移 | 世代ごとの生存セル数と折れ線グラフ |

## 仕組み
各セルの次世代は、前世代の同じ位置を中心とした 3×3 範囲の合計 `S`（自分を含む）で決まります。

```
=IF(OR(SUM(B1:D3)=3, AND(SUM(B1:D3)=4, C2=1)), 1, 0)
```

- `S=3`：誕生、または隣接2個で生存
- `S=4` かつ自分が生：隣接3個で生存

ブロックの周囲（左右の列・上下の空行）を空けているので、盤外は常に死として扱われ、全セル同じ相対式で埋められます。

## 再生成
```
python3 build_lifegame.py   # openpyxl が必要
```
`SIZE`（盤面サイズ）・`GENS`（世代数）を変えて作り直せます。

## Googleスプレッドシート版（自動再生・塗りつぶし入力）
`lifegame.gs` は Google スプレッドシート用の Apps Script です（計算シート不要）。

- 盤面（「ライフゲーム」シート B6:AE35）のセルを**塗りつぶして**ドット絵のように配置します（色は自由、白以外＝生）。
- メニュー「ライフゲーム」→「▶ 再生」で自動再生、「■ 停止」で停止します。塗り直すときは停止してから。
- 次世代の計算はスクリプト内で行い、再生中は盤面をメモリ上に保持して、1世代ごとに塗りをまとめて書き換えます。
- 生き残ったセルは元の色を保ち、誕生したセルは濃紺になります。
- GAS の実行上限（6分）の手前で自動停止するので、続けるときはもう一度「再生」します。

導入：拡張機能 → Apps Script → `lifegame.gs` を貼り付けて保存 → シートを再読み込み（初回は権限を承認）。
